# پوشهٔ بازبینی (خصوصی)

- `review.html` — صفحهٔ تأیید/ردّ پیام‌ها. فقط روی دستگاه خودت باز کن؛ هیچ‌جا آپلودش نکن.
- `approvals.example.json` — نمونهٔ فرمتِ خروجی. فایل واقعی‌ات را با نام `approvals.json` همین‌جا بگذار.

این پوشه وارد خروجی سایت (dist) نمی‌شود. بااین‌حال متن‌های کاندید داخل `src/data/messageCandidates.ts` و `review.html` هستند؛
پس مخزن گیت‌هاب **حتماً Private** باشد (توضیح کامل در README اصلی).
